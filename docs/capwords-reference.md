# CapWords 参考方向

本项目不复制 CapWords 的品牌、文案或界面资产，只借鉴它的产品结构：

- Camera-first：打开后先拍照，不先进入复杂后台。
- Word sticker：识别结果以轻量词语贴纸呈现，而不是长报告。
- Visual memory：照片或视频帧作为记忆锚点。
- No-account start：第一版不强制注册，使用匿名 ID。
- Wordbook：收藏结果形成个人词库。

当前实现保留本项目差异：

- 英语为主、中文辅助解释。
- 保留体育动作英语模式。
- 支持短视频抽帧识别动作。
- 仍提供例句、相关表达、易混词，但在首页以折叠和精简方式呈现。
